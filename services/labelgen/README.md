# labelgen — тиражный профиль печати этикеток

Генерирует печатные листы A4 с этикетками «GeoCoin Parts» из каталога батча,
полученного от `services/provisioning`.

## Что на этикетке (90×54 мм, сетка 2×5 на листе)

- **Шапка**: бренд, «Scan the outer QR to verify before installation»,
  публичный серийник (`unit <первые 16 hex>…`), метка партии.
- **Открытый QR** (слева, 28 мм): кодирует URL страницы проверки
  (`-public-url`, по умолчанию `https://check.geocoin.parts/u/{unit}`).
  Печатается на упаковке открыто — любой может проверить подлинность до покупки.
- **СКРЕТЧ-ЗОНА** (справа, пунктирная рамка): QR инсталляционного кода
  (claim_code без дефисов) + текстовый дубль Base58 группами по 6.
  При печати тиража зона закрывается скретч-наклейкой (рулонная пломба).
- **Подпись** `PUBLIC · verify on geocoin.parts` под открытым QR.

Текст только ASCII (шрифты base-14 Helvetica/Courier в PDF не требуют
встраивания), модули QR рисуются векторно — печать любой плотности.

## Использование

```sh
cd services/labelgen
go run ./cmd/labelgen \
  -batch ../../provisioning-out/batch-0001 \
  -out   ../../provisioning-out/labels-batch-0001 \
  -limit 24 \
  -public-url 'https://check.geocoin.parts/u/{unit}'
```

Выход в `-out`:

| Файл | Назначение |
| --- | --- |
| `labels.pdf` | печатные листы A4 (вектор, Flate-сжатие) |
| `sheet-NN.svg` | те же листы по одному в SVG (типография/правки) |
| `preview.html` | просмотр всех листов в браузере |
| `print-manifest.csv` | сверка тиража: лист/позиция ↔ unit ↔ код |

## Безопасность тиража

`print-manifest.csv` содержит **сырые коды** и хранится с 0600 в каталоге
вывода (в `.gitignore`). После печати и наклейки скретч-слоя манифест
уничтожается; дальше коды существуют только в HSM/тайнике типографии до
записи хешей в `batch_root`. Связь листа с партией: `batch_root` в
манифесте и метка партии в шапке каждого листа.

## Быстрое демо

`scripts/demo-print.sh <batch_dir>` — печатает 24 этикетки и открывает
`preview.html`.
